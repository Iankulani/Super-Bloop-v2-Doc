Commands

Every command starts with !. Type one in the terminal or tap a chip.

!ping <ip>

Test reachability and round-trip time.
!ping 8.8.8.8

!traceroute <ip>

See the path packets take to a host.
!traceroute 1.1.1.1

!nmap <ip>

Find open ports and running services.
!nmap scanme.nmap.org

!curl <url>

Send an HTTP request and read the reply.
!curl -I https://example.com

!ping <ip>

Check whether a host is up and how fast it answers.

# basic ping
!ping 127.0.0.1

# ping with a count
!ping -c 5 1.1.1.1
Tip: Run !ping first to confirm a host is reachable before a heavier scan.

!traceroute <ip>

Follow the route to a target, one hop at a time.

!traceroute google.com

# example output
traceroute to google.com (142.250.185.78), 30 hops max
 1  192.168.1.1      1.2 ms
 2  10.0.0.1         3.4 ms
 3  72.14.215.85     8.1 ms
 4  142.250.185.78  12.5 ms

!nmap <ip>

Scan ports and detect services.

!nmap scanme.nmap.org

# common flags
!nmap -sV 192.168.1.1
!nmap -p 80,443 10.0.0.5
Ethical use: Only scan systems you own or have written permission to test.

!curl <url>

Send HTTP and HTTPS requests and inspect headers.

!curl https://example.com

# headers only
!curl -I https://example.com

# POST request
!curl -X POST -d '{"key":"value"}' https://api.example.com

Quick reference

CommandWhat it doesExample
!ping <ip>ICMP echo request!ping 8.8.8.8
!traceroute <ip>Trace the network path!traceroute 1.1.1.1
!nmap <ip>Port scan!nmap scanme.nmap.org
!curl <url>HTTP client!curl -I https://example.com

Try it in order

  1. Type !ping 127.0.0.1 to test connectivity.
  2. Use !traceroute 1.1.1.1 to see the route.
  3. Run !nmap scanme.nmap.org to list open ports.
  4. Fetch headers with !curl -I https://example.com.
How do I run a command?

Tap a chip in the terminal, or type a command in the input and press Run or Enter. The terminal prints a simulated reply.

Are these results real?

No. This page is an interactive demo with simulated output. Real ping, traceroute, nmap and curl must run in a proper shell.
